# Фоточка — лендинг фотопечати с калькулятором

Учебный проект. Клиент считает стоимость печати, оформляет заказ онлайн и забирает его в пункте выдачи.

- `public/` — сайт: лендинг, калькулятор (`calc.js` — общий для сайта и сервера), форма, страница «Заказ оформлен», документы, свои шрифты.
- `server/server.js` — сервер на Node.js 22 без внешних библиотек: приём заказов, пересчёт суммы, база SQLite, защита от спама, уведомление менеджеру во ВКонтакте, страница `/admin` со списком заказов.
- `tests/` — 41 автотест: расчёт по таблице тест-кейсов + 5 сценариев ТЗ через сервер. Запуск: `npm test`.
- `tools/xlsx_to_json.py` — обновление прайса из `prais_fotopechat.xlsx`.
- `deploy/`, `DEPLOY.md` — выкладка на VPS и настройка ВК.

Локальный запуск: `cp .env.example .env` → `npm start` → http://127.0.0.1:3047
